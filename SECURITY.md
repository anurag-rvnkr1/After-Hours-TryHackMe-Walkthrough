# Security Policy

## Scope

This repository contains documentation for an authorized TryHackMe training challenge. It is not a production security tool and should not be used against systems without permission.

## Safe-publication policy

The public repository intentionally omits challenge passwords, complete encoded payloads, and the recovered flag. Suspicious binaries are not distributed here.

## Reporting

For repository-specific issues, open a GitHub issue with enough context to reproduce the documentation problem, but do not publish credentials, challenge secrets, or third-party private information.
